# Contribuir

1. Abre una issue con propósito, alcance y riesgo.
2. Trabaja en una rama corta y enfocada.
3. Incluye pruebas o evidencia reproducible.
4. No agregues datos personales, credenciales ni afirmaciones institucionales sin fuente verificable.
5. Solicita revisión mediante pull request.

Al contribuir aceptas que tu aportación se distribuya bajo la licencia del proyecto correspondiente.
