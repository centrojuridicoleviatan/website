# Política de seguridad

## Reportar una vulnerabilidad

Utiliza el canal privado de GitHub para reportar vulnerabilidades de este repositorio:

https://github.com/centrojuridicoleviatan/website/security/advisories/new

No publiques vulnerabilidades en Issues, Pull Requests, Discussions ni otros canales públicos. Incluye el activo afectado, impacto, pasos reproducibles y la evidencia mínima necesaria. No incluyas datos personales de terceros ni secretos innecesarios.

## Investigación de buena fe

No se autorizan pruebas destructivas, ingeniería social, denegación de servicio, acceso persistente, extracción de datos ni pruebas sobre activos de terceros. Detén la prueba si encuentras información sensible y notifícanos mediante el canal privado.

Intentaremos acusar recibo en 5 días hábiles y proporcionar una primera evaluación en 10 días hábiles. Estos plazos son objetivos operativos, no garantías. Coordinaremos la divulgación según el riesgo y la disponibilidad de una corrección.

## Alcance

Solo los activos publicados expresamente por LEVIATÁN se consideran dentro de alcance. La ausencia de un activo implica que está fuera de alcance.
